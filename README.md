# 💱 Conversor de Moedas em Java

Este é um projeto simples de conversor de moedas desenvolvido em Java, que utiliza a API pública da [ExchangeRate API](https://www.exchangerate-api.com/) para obter as taxas de câmbio em tempo real.

## 📌 Funcionalidades

- Conversão entre as seguintes moedas:
  - Dólar (USD) ↔ Real (BRL)
  - Euro (EUR) ↔ Real (BRL)
  - Dólar (USD) ↔ Euro (EUR)
- Obtenção automática da taxa de câmbio atual via API
- Menu interativo no terminal
- Tratamento de entrada do usuário

## 🛠️ Tecnologias utilizadas

- Java 21
- Biblioteca [Gson](https://github.com/google/gson) para parsing de JSON
- IntelliJ IDEA para desenvolvimento
- API: [https://v6.exchangerate-api.com](https://www.exchangerate-api.com/)
